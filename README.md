# Kontor

AH-Addon für World of Warcraft: Forever. Slash-Befehl `/kontor`.

## Installation

1. Den Ordner `Kontor` aus diesem Repository herunterladen
   (Branch als ZIP herunterladen, entpacken, darin liegt der Ordner `Kontor`).
2. Den Ordner `Kontor` in das AddOns-Verzeichnis des Spiels kopieren, in der Beta:
   `World of Warcraft\_classic_beta_\Interface\AddOns\Kontor`
   Darin muss direkt die Datei `Kontor.toc` liegen.
3. Spiel starten bzw. `/reload`.
